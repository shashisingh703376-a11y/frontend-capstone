# Frontend Capstone

A frontend web application built as a capstone project. This repository holds the client-side code, documentation, and project conventions.

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (included with Node.js)
- Git

## Setup

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd frontend-capstone
   ```

2. Install dependencies (once a `package.json` is added):

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

   If the project uses Vite or a similar toolchain, use `npm run dev` instead.

4. Open the URL printed in the terminal (typically `http://localhost:3000` or `http://localhost:5173`).
